- **18 พ.ย. (เพิ่มเติม):** เนื้อเรื่องภาค 3 "ดาวสุขใจ" (ข้อ 51–60) • คัตซีนลื่นขึ้น • เหรียญตราใหม่ 7 อัน • ความเร็ว HDD/SSD สมจริง • ขยะรีไซเคิลได้ ฿5 ที่ถังขยะ • โอกาสสุ่มเหตุการณ์ลดเหลือ 18% • ปุ่มแอดมินล้างยูแสนสุข • พี่ก้อย คนเก็บของเก่า รับซื้อขยะ (ตัวละครใหม่)
- **18 พ.ย. (ล่าสุด):** ของเก็บตามพื้นในหมู่บ้าน (ผักกูด เห็ด บัว มะม่วง มะพร้าว หอย มะลิ) วาดเป็นภาพเวกเตอร์เอง ไม่พึ่งฟอนต์อีโมจิ — เห็นชัดบน PC ทุกเครื่อง มีวงเรืองแสง ขอบเข้ม เงา และลอยเบาๆ
- **19 พ.ย.:** โมเดลของในบ้านแนว 3D (มีหน้าบน/ข้าง/เงา/ไฮไลต์) ของบ้านข้าวหอม กล้า ธีร์ ลุงชัย ใบเตย มะลิ ปู่เทียน ยายสี ภูมิ น้ำฝน ต้นกล้า: โต๊ะช่างไม้ เรือจำลอง กล่องเครื่องมือ ตู้ยา ไวโอลิน ที่เก็บเบ็ด โต๊ะม้วนคัมภีร์ ธง แท่นตะเกียง ถังดอกไม้ เตียง โต๊ะ โคมไฟ กระถางต้นไม้ พรม • รถเข็นซาเล้งพี่ก้อยวาดใหม่ และแก้บัครถจอดค้างกลางลาน ตอนนี้ตามพี่ก้อยไปเก็บขยะ และจอดข้างกระท่อมตอนพัก
- **19 พ.ย. (ดวล):** ทุกสกิล (12 สกิล) ใช้ในลานประลองตอนดวลกับเพื่อนได้แล้ว — ฟ้าผ่า/พายุน้ำแข็ง/แผ่นดินไหว/ไฟล้อมกาย/พายุหมุน/ฝนดาวตก/พุ่งตัว/ออร่า ทำดาเมจใส่คู่ต่อสู้ • ดูดเลือด/ฟื้นฟู/ออร่า ฟื้น HP จริง • โล่ลดดาเมจ 65% (เซิร์ฟเวอร์นับ) • ปลุกพลังดาบเพิ่มดาเมจ 60% • เขียนรายละเอียดโหมดดวลในหน้าสกิลทุกสกิล • เซิร์ฟเวอร์ room.js เพิ่ม pvp:heal / pvp:buff (งบฟื้นรวม 120 ต่อดวล โล่ใช้ซ้ำทุก 30 วิ)
- **19 พ.ย. (ไวรัส):** คอมในเกม: ไวรัสสุ่มติดมีอยู่เดิม (เปิดลิงก์เสี่ยง/ออนไลน์ตอนไม่มีแอนตี้ไวรัส) ตอนนี้มี 6 ชนิดมีชื่อ (Trojan/Adware/Worm/Miner/Spy/Rootkit) บางตัวซ่อนลึก • แอป สุขการ์ด มี สแกนด่วน (4 วิ) กับ สแกนเต็มรูปแบบ (10 วิ) แสดงจำนวนไฟล์ที่ตรวจ + ประวัติการสแกน • สแกนด่วนไม่เจอไวรัสซ่อนลึก ต้องใช้สแกนเต็ม
- **19 พ.ย. (ของตามแมพ):** ของเก็บตามพื้น (ผักกูด เห็ด บัว มะม่วง ฯลฯ) ปรับภาพให้ใกล้เคียงหินกับเส้นใย — วางบนพื้นมีเงา มีกอหญ้ารอบโคน โยกตามลม ไม่มีวงเรืองแสง • เส้นใยดรอปมากขึ้น: ถอนหญ้ารกได้เส้นใย 2–3 ชิ้น (เดิม 1–2) กอหญ้ารกต่อวันเพิ่มจาก 10 เป็น 18 ในไร่ และสุ่มขึ้นในโซนหาของป่ารอบหมู่บ้านด้วย
- **19 พ.ย. (ร้านคอม):** แท็บร้านคอมออนไลน์: สั่งอัปเกรด CPU/RAM/การ์ดจอ ฯลฯ แล้วมีกล่องยืนยันสีเขียว (ชิ้นไหน ราคา ถึงวันที่เท่าไร เครื่องยังใช้ชิ้นเดิมจนกว่าพัสดุมา) + รายการ "📦 กำลังจัดส่ง" + คำอธิบายแยกหมวด "อัปเกรดชิ้นส่วนในเครื่อง" ออกจาก "อะไหล่สำรอง" (เดิมสั่งแล้วดูเหมือนไม่มีอะไรเกิดขึ้น เพราะของส่ง 2–3 วัน)
- **19 พ.ย. (ขายอะไหล่เก่า):** ร้านคอมออนไลน์มีกล่อง "🎒 มีอะไหล่เก่า N ชิ้น — ขายได้!" ด้านบน พร้อมปุ่ม ขายทั้งหมด (ข้ามดิสก์ที่มีข้อมูล) และปุ่มขายทีละชิ้นเดิมด้านล่าง • ข้อความพัสดุมาถึงบอกว่าชิ้นเก่าขายได้ที่ร้านคอม
- **19 พ.ย. (เน็ตฟรี):** เพิ่มแพ็ก "เน็ตฟรี 365 Kbps" — ฟรี ไม่หมดอายุ ใช้ได้ทันทีไม่ต้องรอช่าง แต่ช้ามาก (ปิงสูง ผู้ชมสตรีมน้อย) และหลุด/ออฟไลน์สุ่มบ่อย (ทุก ~0.3–1 วันเกม ครั้งละ 45–180 นาทีเกม) แม้ไม่ได้เปิดโหมดท้าทาย • เลือกที่ร้านคอมหรือแผงเน็ตในคอม แพ็กเสียเงินยังเสถียรกว่า
- **19 พ.ย. (ฟิตเนส):** ระบบออกกำลังกายเพิ่มหลอดสูงสุดถาวร — เลเวลฟิตเนส 0–15 ทุกเลเวล ❤️ พลังชีวิตสูงสุด +3 / ⚡ พลังงานสูงสุด +4 (รวมสูงสุด +45 / +60) • แต้มมาจากการวิ่ง (ทุก 45 วิ = +1 วันละไม่เกิน 8) และปุ่มออกกำลังกายในหน้า สถานะ (จ็อกกิ้ง/ยกน้ำหนัก/โยคะ วันละ 3 รอบ ใช้พลังงานและความอิ่ม ป่วยอยู่ทำไม่ได้)
- **19 พ.ย. (รีเซ็ตอันดับ):** อันดับหน้าแรก (รวย/ผู้ติดตาม/วันที่เล่น) รีเซ็ตอัตโนมัติทุก 7 วัน — หลังรีเซ็ตนับเฉพาะที่เพิ่มขึ้นในรอบใหม่ เก็บแชมป์ 1–3 รอบก่อนไว้โชว์ • แอดมินปรับจำนวนวันได้ (0 = ไม่รีเซ็ตเอง) หรือกด "รีเซ็ตอันดับตอนนี้" ในแผงแอดมิน (บันทึกลงล็อกการกระทำ) • รายชื่อเพื่อนไม่ถูกรีเซ็ต
- **19 พ.ย. - **19 พ.ย. (หมาตัวเดียว):** หมาเป็นตัวเดียวกันทั้งในและนอกบ้าน (`S.pet.loc`) มีกิจวัตรเอง: กลางคืน 21:00–06:00 / ฝนตก / งีบบ่ายสุ่ม → เดินไปประตูบ้านแล้วเข้าไปนอนเอง, เช้าหรือฝนหยุดก็เดินออกมาเอง • ผู้เล่นเข้าบ้านตอนหมาอยู่ใกล้ (≤520px) และไม่ได้สั่งให้รอ หมาตามเข้ามา • ตอนอยู่ในบ้านถึงเวลาก็เดินไปประตูออกเอง • ตอนอยู่ในบ้านจะไม่โผล่ข้างนอก/ไม่ส่งตำแหน่งออนไลน์
- **19 พ.ย. (แก้ป้ายออนไลน์ทับชิป):** สาเหตุจริง: `place()` ของระบบออนไลน์เซ็ต `top` แบบ inline ทับตัวแปร `--mpt` และไม่นับชิปสถานะ (บัฟ/ป่วย/กระเป๋าเต็ม) → ตอนนี้ `place()` คำนวณจากขอบล่างของ HUD + ชิป แล้วเซ็ต `--mpt` ทุก 0.5 วิ
- **19 พ.ย. (รถเข็นพี่ก้อย + กระเป๋า):** แก้ด้ามรถเข็นให้หันเข้าหามือพี่ก้อย (เดิมหันตามทิศที่รถไหล เลยชี้ออกจากตัว) รถอยู่ด้านหลังตามทิศเดิน ขึ้น/ลงจะอยู่ข้างตัวด้านเดิม • กระเป๋า 16→32 ช่อง และแผงขายขยาย ×2: 72 / 144 / 256 ช่อง (ราคาเท่าเดิม ฿5,000 / ฿20,000 / ฿700,000)
- **19 พ.ย. (แก้ไร่กาฟิวตัดไม้ไม่ได้):** กฎ "ห้ามตัดไม้เขตวัด" ตรวจแค่ x≥50, y≤13 ซึ่งไปครอบแมพไร่กาฟิว (x 96+) ด้วย → จำกัดเฉพาะแมพหมู่บ้าน (x<96) • กฎวันพระ (งดตัดไม้/ตกปลา/วิ่งในวัด/วิ่งช่วงเคารพธง) ก็จำกัดเฉพาะหมู่บ้านเช่นกัน ไร่กาฟิวทำได้ตามปกติ

  - 🧘 ยืนนิ่งๆ/พักผ่อน พลังงานค่อยๆ ฟื้น +5 ต่อ 10 นาทีในเกม (เหมือนแช่ออนเซ็น) ไม่เกินพลังงานสูงสุด ขยับตัวแล้วหยุดฟื้น (แทนระบบ "วิ่งเพิ่มพลังงานสูงสุด" ที่เข้าใจผิดไปก่อนหน้า)

- **20 พ.ย. (พระ/ใส่บาตร/ไวรัสแฝง):**
  - 🙏 ผู้เล่นหญิงเข้าใกล้พระได้ถึง 1 ช่อง (เดิม 2.2 ช่อง `MONK_NEAR`) • พระเดินตามเส้นทางบิณฑบาตปกติเสมอ ไม่อ้อมใคร • ผู้เล่นหญิงเป็นฝ่ายหลบเอง: เดินเข้าใกล้พระไม่ได้ และถ้าพระเดินมาใกล้เกิน 1 ช่อง ตัวเราถูกขยับออกข้างๆ/ถอย (`monkPush`)

- **เวลาทดลองเล่น:** ผู้ที่ยังไม่ล็อกอินเล่นได้ 2 ชั่วโมง (ผู้ดูแลปรับหรือปิดได้) แล้วต้องสมัครสมาชิกก่อนเล่นต่อ เซิร์ฟเวอร์เป็นคนนับเวลา เซฟในเครื่องไม่หาย
- **หน้าแรกดีไซน์ใหม่:** ฉากหมู่บ้านพร้อมป้ายไม้ทางเข้าเกม แสดงจำนวนคนออนไลน์ และปุ่มบัญชี
- **เครื่องมือผู้ดูแล:** ผู้ดูแลมาจากบัญชีจริง (ยืนยันด้วยรหัสตั้งต้นฝั่งเซิร์ฟเวอร์) ไม่มีรหัสผ่านฝังในเกมอีกแล้ว ดูรายชื่อบัญชี ระงับ/คืนสิทธิ์ ตั้งรหัสผ่านชั่วคราว ลบบัญชี ปลดการผูกไอดีกับเซฟ ดูและล้างบันทึกการกระทำของผู้ดูแล
- **ล็อกเกม:** ผู้ดูแลล็อกบ้านสวนสุขใจหรือลิขิตชีวิตพร้อมข้อความแจ้งได้ ฝั่งเซิร์ฟเวอร์บล็อกหน้าเกมและการเชื่อมต่อออนไลน์ และเตะผู้เล่นออกจากห้องเมื่อล็อกบ้านสวนสุขใจ
- **ตลาดนัดประจำสัปดาห์:** สินค้าหายากหมุนเวียนทุกสัปดาห์ที่แผงของใช้ช่าง
- **โรงสีและเตาอบ:** โรงสีแป้งโม่ผักผลไม้เป็นแป้ง เตาอบใช้แป้ง ไข่ น้ำผึ้ง อบขนมปัง คุกกี้ เค้ก
- **คุณภาพผลผลิตและโอ่งหมักดอง:** ผลผลิตมีระดับธรรมดา/ดี/เยี่ยม และโอ่งหมักดองแปรรูปผัก ผลไม้ ปลา เป็นของที่ขายได้ราคาสูงกว่า
- **เส้นทางชีวิต:** ตอนสร้างตัวละครต้องเลือก 🌾 ชาวไร่ หรือ 🎮 สตรีมเมอร์ (เลือกแล้วเปลี่ยนไม่ได้) ชาวไร่ได้ผู้ชม/รายได้/ผู้ติดตามจากไลฟ์สดเหลือ 60% และปลดล็อกวิดีโอ 4K กับสปอนเซอร์เมื่อมีผู้ติดตาม 5,000 คน ส่วนสตรีมเมอร์ได้ XP ฟาร์ม 70% โอกาสผลผลิตคุณภาพดีลดครึ่ง และต้องมีทักษะฟาร์มเลเวล 4 ถึงจะวางเครื่องแปรรูปได้ เซฟเก่าไม่ถูกลดอะไร

- **เล่น 2 จอ:** หน้า `split.html` เล่นสองคนบนจอเดียวกัน (ซ่อนลิงก์จากหน้าแรกชั่วคราว) รองรับโทรศัพท์: ย่อปุ่ม/HUD/กล่องคุยอัตโนมัติเมื่อช่องเล็ก แนวตั้งแบ่งบน-ล่าง แนวนอนแบ่งซ้าย-ขวา จอที่ 2 เชื่อมออนไลน์ในฐานะผู้เล่นทั่วไปเสมอ

## 🏡 ชีวิตที่เลือกได้เอง

ชีวิตประจำวันในบ้านสวนไม่ได้ถูกกำหนดไว้ตายตัว

- 🌾 ปลูกและเก็บเกี่ยวพืช
- 🐕 เลี้ยงสัตว์เลี้ยง
- 🐔 เลี้ยงสัตว์ในฟาร์ม
- 🎣 ตกปลาและเล่นมินิเกมตกปลา
- ⛏️ ลงเหมืองและหาแร่
- 🪓 ใช้เครื่องมือจัดการพื้นที่
- 🍳 ทำอาหาร
- 💰 ซื้อขายและเก็บเงิน
- 🏠 อัปเกรดบ้าน
- 🪑 ตกแต่งบ้าน
- 🗺️ เดินทางและสำรวจพื้นที่
- 🎊 เข้าร่วมเทศกาล
- 💬 พูดคุยกับชาวบ้าน
- ❤️ สร้างความสัมพันธ์
- 💍 แต่งงานและใช้ชีวิตคู่กับตัวละครที่รองรับ

สิ่งต่าง ๆ เชื่อมต่อกันเป็นชีวิตประจำวันเดียวกัน ผู้เล่นจึงสามารถเลือกได้ว่าจะใช้เวลาไปกับฟาร์ม การสำรวจ ผู้คน หรือเรื่องราวในหมู่บ้าน

## 👤 ตัวละครของคุณ

ก่อนเริ่มชีวิตในบ้านสวน ผู้เล่นสามารถสร้างตัวละครของตัวเองได้ ทั้งชื่อ ชื่อไร่ วันเกิด นิสัย รูปลักษณ์ เสื้อผ้า และสัตว์เลี้ยง

นอกจากนี้ยังมีระบบปรับแต่งรูปลักษณ์ของตัวละคร และสามารถนำภาพของตัวเองมาใช้ในบางส่วนของตัวละครได้

เมื่อเล่นไปเรื่อย ๆ ตัวละครจะพัฒนาทั้งระดับ ความสามารถ เครื่องมือ เงิน ของสะสม และความสัมพันธ์กับผู้คนในหมู่บ้าน

## ❤️ ผู้คนในหมู่บ้าน

หมู่บ้านไม่ได้มีเพียงฉากหลัง

ผู้คนมีตารางเวลา สถานที่ที่ไปเป็นประจำ นิสัย ความชอบ และเรื่องราวของตัวเอง การพูดคุยกับพวกเขาจึงเป็นอีกส่วนหนึ่งของการเดินทางในบ้านสวน

### 🎨 น้ำฝน
นักวาดภาพของหมู่บ้าน ผู้ที่ใช้ศิลปะเป็นส่วนหนึ่งของชีวิตประจำวัน

### 🩺 ใบเตย
หมอประจำหมู่บ้าน ผู้คอยดูแลผู้คนในชุมชน

### 🌸 มะลิ
เจ้าของสวนดอกไม้ ผู้ที่อยู่ใกล้ชิดกับโลกของดอกไม้และธรรมชาติ

### 🪚 ข้าวหอม
ช่างไม้ ผู้มีบทบาทเกี่ยวกับงานไม้และการสร้างสิ่งต่าง ๆ

### 🎵 ภูมิ
ชาวประมงนักดนตรี ผู้ที่มีทั้งชีวิตอยู่กับสายน้ำและเสียงเพลง

### 🚤 กล้า
ช่างต่อเรือ ผู้เชี่ยวชาญด้านเรือและพื้นที่ริมสายน้ำ

### 📚 ธีร์
บรรณารักษ์ ผู้ดูแลเรื่องราวและหนังสือภายในชุมชน

### 🎮 ต้นกล้า
นักเล่นเกมประจำหมู่บ้าน อีกหนึ่งตัวละครที่สะท้อนบรรยากาศของคนรุ่นใหม่

### 🌳 ลุงชัย
ผู้ใหญ่บ้าน ผู้มีบทบาทสำคัญต่อชุมชนและเส้นเรื่องหลักของเกม

### 👩‍🏫 ครูพิมพ์
ครูประจำโรงเรียน ผู้ดูแลเด็ก ๆ และชีวิตของโรงเรียนในหมู่บ้าน

### 👦 น้องกล้วย
นักเรียนชั้น ป.3 หนึ่งในเด็ก ๆ ที่ทำให้หมู่บ้านมีชีวิตชีวามากขึ้น

### 👧 น้องฟ้า
นักเรียนชั้น ป.4 อีกหนึ่งตัวละครเด็กที่ผู้เล่นสามารถพบได้ในหมู่บ้าน

### 🛒 ป้าแดง
เจ้าของร้านชำ แหล่งซื้อขายของใช้และสิ่งจำเป็นในชีวิตประจำวัน

### 👗 ป้าลัดดา
ช่างตัดเสื้อผ้าไทย ผู้เกี่ยวข้องกับเสื้อผ้าและการแต่งตัวของชุมชน

### 🧓 ปู่เทียน
ผู้เฒ่าผู้รักษาศาล ตัวละครที่ผูกพันกับสถานที่สำคัญแห่งหนึ่งของหมู่บ้าน

### 🙏 หลวงพี่สุข และ หลวงพี่ใจ
พระประจำวัดสุขใจ ผู้ดูแลชีวิตและบรรยากาศของวัดในชุมชน

ชาวบ้านแต่ละคนมีตารางเวลา สถานที่ และความสัมพันธ์ของตัวเอง พวกเขาจะเดินทางไปตามบ้าน โรงเรียน ร้านค้า สวน ทะเลสาบ ท่าเรือ วัด และลานหมู่บ้านตามช่วงเวลาต่าง ๆ

รายละเอียดบางอย่างของตัวละครควรได้พบด้วยตัวเองระหว่างเล่น

## 💕 ความสัมพันธ์

ความสัมพันธ์เป็นส่วนหนึ่งของชีวิตในบ้านสวน

ผู้เล่นสามารถพูดคุยกับชาวบ้าน มอบของที่ชอบ เพิ่มระดับหัวใจ และค่อย ๆ รู้จักเรื่องราวของแต่ละคนมากขึ้น

ตัวละครแต่ละคนมีสิ่งที่ชอบ รัก หรือไม่ชอบแตกต่างกัน จึงต้องสังเกตและทำความรู้จักกันจริง ๆ

สำหรับตัวละครที่รองรับ ผู้เล่นสามารถพัฒนาความสัมพันธ์ไปจนถึงการแต่งงานและใช้ชีวิตคู่ได้

## 📖 เส้นทางหลักของเรื่องราว

เรื่องราวเริ่มจากการใช้ชีวิตธรรมดา ๆ ในหมู่บ้าน ก่อนจะค่อย ๆ ขยายไปสู่การสร้างฟาร์ม พัฒนาตัวละคร สำรวจเหมือง สร้างความสัมพันธ์ และมีส่วนร่วมกับชุมชน

ภารกิจช่วงแรกจะค่อย ๆ สอนให้ผู้เล่นรู้จักการทำไร่ ตกปลา ลงเหมือง ทำอาหาร พบปะชาวบ้าน และเริ่มสร้างชีวิตของตัวเอง

เมื่อเล่นต่อ เรื่องราวจะขยายไปสู่การพัฒนาฟาร์ม การพัฒนาตัวละคร การสำรวจเหมือง ความสัมพันธ์ บ้าน และเหตุการณ์สำคัญของชุมชน

- 💕 ระบบแต่งงานและชีวิตคู่

### 🎯 Game Core

`public/game-core/baan-suan-sukjai-core.html`

ส่วนนี้เป็นหัวใจของเกม ทั้งโลก ระบบการเล่น UI ตัวละคร ภารกิจ และเนื้อหาหลักอยู่ที่นี่

### 🌐 ระบบออนไลน์

ฝั่งออนไลน์ทำงานผ่าน Worker และ Durable Object โดยมีไฟล์สำคัญคือ

- `src/index.js`
- `src/room.js`
- `src/auth.js` และ `src/auth-core.js` (บัญชี เซฟออนไลน์ เครื่องมือผู้ดูแล)
- `wrangler.jsonc`

การตั้งค่าที่ต้องมีบน Cloudflare: Durable Object binding `GAME_ROOMS` และ `ACCOUNTS` และ secret `ADMIN_SETUP_CODE` (อย่างน้อย 12 ตัวอักษร) สำหรับใช้ตั้งบัญชีแรกเป็นผู้ดูแล ตั้งด้วย `npx wrangler secret put ADMIN_SETUP_CODE` แล้วดีพลอยด้วย `npx wrangler deploy` • ต้องตั้งเป็นชนิด **Secret** (เข้ารหัส) เท่านั้น ไม่ใช่ Variable แบบข้อความ เพราะ Secret ไม่ถูกรีเซ็ตตอนอัปเดตอัตโนมัติจาก GitHub (ใน `wrangler.jsonc` ตั้ง `keep_vars: true` กันตัวแปรที่ตั้งผ่านหน้าเว็บ Cloudflare ถูกลบตอน deploy ด้วย)

**เจ้าของเว็บไซต์ (Owner):** ตั้ง secret `OWNER_SETUP_CODE` (อย่างน้อย 12 ตัวอักษร คนละชุดกับ `ADMIN_SETUP_CODE`) แล้วกรอกที่หน้าบัญชี → "👑 ตั้งเป็นเจ้าของเว็บไซต์" • เจ้าของมีสิทธิ์แอดมินทั้งหมด และเหนือกว่าแอดมิน: ให้แอดมินชั่วคราว (1 ชม./6 ชม./1 วัน/3 วัน/7 วัน/30 วัน) หรือถาวร, ถอนสิทธิ์แอดมิน, ระงับ/ลบ/รีเซ็ตรหัสบัญชีแอดมินได้ • แอดมินแตะบัญชีเจ้าของไม่ได้ และแอดมินชั่วคราวจะถูกลดเป็นผู้เล่นปกติเองเมื่อหมดเวลา • การกระทำทั้งหมดอยู่ในบันทึกแอดมิน • เจ้าของกด "เลิกเป็นเจ้าของเว็บไซต์" ได้เองที่หน้าบัญชี (กลับเป็นผู้เล่นปกติ) • รหัสผ่านเก็บเป็นแฮช ไม่มีใครดูรหัสจริงได้ — ถ้าผู้เล่นลืม ให้ใช้ "ตั้งรหัสชั่วคราว"
