# ชุดทดสอบ (เก็บสำรองไว้ชั่วคราว)

ไว้รันก่อน push เพื่อกันของพังย้อนหลัง • **ลบโฟลเดอร์ `tests/` ทิ้งได้เมื่อทดสอบเสร็จและไม่ใช้แล้ว** (ไม่มีอะไรในเกมจริงอ้างถึงมัน)

- รันทั้งหมด: `bash tests/run.sh` (ต้องมี Node กับ Playwright + Chromium: `npm i -g playwright`)
- แต่ละไฟล์รันเดี่ยวได้ เช่น `NODE_PATH=$(npm root -g) node tests/monk.test.js`
- `mkinst.js` ทำสำเนาเกมที่เปิดตัวแปรภายใน (`__ev`) เฉพาะตอนทดสอบ ไม่แตะไฟล์เกมจริง

| ไฟล์ | ทดสอบอะไร |
|---|---|
| `owner.test.mjs` | เจ้าของเว็บไซต์/แอดมินชั่วคราว (ฝั่งเซิร์ฟเวอร์) |
| `monk.test.js` | เมนูธรรมะ/พระวินัย เทศน์วันพระ กฎถวายของหลังเที่ยง |
| `gym.test.js` | มินิเกมฟิตเนส (กันกดซ้ำ รับแต้มครั้งเดียว ปิดแล้วไม่ค้าง) |
| `streamer-start.test.js` | สายสตรีมเมอร์เริ่มด้วยโน้ตบุ๊ก RAM 2 GB + เน็ตฟรี และเซฟเก่าย้ายระดับ RAM |
| `daily.test.js` | ยืนนิ่งฟื้น +5 และอาหารทิพย์ทุกเช้า |
| `auto-update.test.js` | แถบอัปเดตอัตโนมัติ (เซิร์ฟเวอร์จำลอง) |
| `login-refresh.test.js` | กดเข้าสู่ระบบสำเร็จแล้วรีเฟรช 1 ครั้ง ไม่วนซ้ำ |
